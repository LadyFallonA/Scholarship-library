              How this works

              This center is built from three GitHub pieces that anyone in the Evolve community can use:

              • Library
                data/scholarships.json in the Scholarship-library repository. Families suggest new opportunities through the Suggest a scholarship form; each one is checked against the official source before it's added.
              • Scholarship Tracker
                GitHub Project board. Each application is an issue with a student code, deadline, and status label.
              • Calendar & Reminders
                The project's roadmap view, plus downloadable calendar files with built-in reminders.
              • Essay Vault
                A private Scholarship-essays repository with a story bank, prompt bank, and drafts by student code.

              Scholarship information is provided for planning only. Sponsors change rules and dates — always confirm on the official link before applying. Never pay a fee to apply for a scholarship.
